# Points-Detector

Обнаружение точек и восстановление траекторий по сериям данных.

## О проекте

Проект предназначен для обработки серий измерений (точек) и восстановления траектории движения объекта. Реализованы модули обнаружения точек, интерполяции пропущенных значений и решения задачи восстановления траектории.

## Структура репозитория

```
Points-Detector/
├── detector.py        # Обнаружение точек в данных
├── interpolation.py   # Интерполяция и сглаживание
├── solver.py          # Восстановление траектории
├── test.py            # Скрипт проверки на сериях данных
├── data/
│   ├── 0001/
│   │   ├── points.txt
│   │   └── trajectory_points.txt
│   ├── 0002/
│   └── ...
└── __pycache__/
```

## Данные

Каждая серия в `data/` содержит:

- `points.txt` — исходные точки, полученные в серии измерений;
- `trajectory_points.txt` — эталонная/восстановленная траектория.

## Текущий статус

Точки успешно обнаруживаются в сериях: **1, 2, 3, 4, 6, 7**.
